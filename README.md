### 🚀 Featured Project

#### [BIM Automation Library](https://github.com/bvoltz/BIM-Automation-Library)
A lightweight **Common Data Environment (CDE)** for Autodesk Revit models, guided by **ISO 19650** principles.

- ⬆️ Python uploads native `.rvt` models to cloud storage and records metadata in PostgreSQL
- 🔐 **Per-user Row-Level Security** on both data and files: users only see their own models
- ✅ Automated tests prove that other users and anonymous requests are blocked
- 🗺️ Roadmap: pyRevit "Publish to CDE" button, ISO 19650 naming and revision codes, audit trail, dashboards

`Python` · `Supabase` · `PostgreSQL` · `pyRevit` · `Revit API`
